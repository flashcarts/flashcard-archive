R4iTT 3DS NEW is compatible with BL2CK OS, which forks from the last official RTS firmware.

Download the BL2CK 1.31.0 kernel:
    https://archive.flashcarts.net/BL2CK/BL2CK_1.31.0.zip

The latest firmware update for the cart can be found in ./r4itt.net_3DS_NEW_FWUpdate_5.06/

cheats:
    - BL2CK: __rpg/cheats/usrcheat.dat
    - r4itt.net_3DS_NEW_Kernel_2.37 (old) SYSTEM/cheats/usrcheat.dat
