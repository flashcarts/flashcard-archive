DON'T RENAME THE FILE BEFORE YOU UPDATE THE FIRMWARE
THE FIRMWARE UPDATE FILE MUST BE PLACED ON THE ROOT OF MICROSD

V20 firmware update will wipe out and reprogram the whole bootloader, it needs the r4iUp_v20.nds keeping original file name to be the reprogram data source.
rename the file will cause reprogram process fail and your flashcard bricked.


此次升级将会完整擦除整个Bootloader，请不要更改V20升级文件名，必须保持为r4iUp_v20.nds，并且文件必须存放在TF卡的根目录，修改文件名会导致升级失败，卡带变砖.
